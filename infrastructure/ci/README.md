# CI Standard

CI should validate:

- lint;
- static analysis;
- architecture boundaries;
- unit tests;
- integration tests;
- contract tests;
- security scans;
- dependency scans;
- secret scans;
- migration dry-runs;
- documentation link checks.

CI vendor options:

- GitHub Actions;
- GitLab CI;
- Jenkins;
- Bitbucket Pipelines.

The pipeline contract matters more than the vendor.
